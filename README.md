# Titanic Data Cleaning and Preprocessing

This project focuses on data cleaning and preprocessing of the Titanic dataset using Python and Pandas.

## Project Contents

- `data/` – Contains the original Titanic dataset.
- `cleaned_data/` – Contains the cleaned Titanic dataset.
- `notebooks/` – Contains the Python scripts used for data cleaning and preprocessing.

## Technologies Used

- Python
- Pandas
- Jupyter Notebook

## Dataset

The project uses the Titanic dataset and performs data cleaning and preprocessing to prepare the data for further analysis.
